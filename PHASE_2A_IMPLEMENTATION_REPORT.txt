==================================================
INSTALLATION ISSUE DETAILS
==================================================

Issue: face_recognition_models incompatible with Python 3.14

Root Cause:
The face_recognition_models package (v0.3.0, last updated 2018) depends
on pkg_resources from setuptools. Python 3.14 removed pkg_resources in
favor of importlib.resources.

Error: ModuleNotFoundError: No module named 'pkg_resources'

Impact:
- face_recognition library is installed but cannot be imported
- Face recognition functionality blocked until resolved
- Face detection (MediaPipe), image processing (OpenCV), and other
  CV operations remain fully functional

Resolution Options:
1. Use Python 3.11 or 3.12 (RECOMMENDED for immediate continuation)
2. Wait for face_recognition package update
3. Use patched face_recognition_models from GitHub
4. Consider alternative libraries (requires architecture change)
