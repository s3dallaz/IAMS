# Intelligent Attendance Monitoring System Using Computer Vision

## 📌 Overview

This project is an AI-powered attendance system that automates student attendance using Computer Vision and face recognition techniques. The system detects and recognizes faces in real-time, records attendance, and tracks student presence duration during lectures.

## 🚀 Features

* Real-time face detection and recognition
* Automatic attendance recording
* Attendance duration tracking
* Late arrival and early leaving detection
* Liveness detection to prevent cheating
* Manual identity verification using student ID
* Adaptive face data updating for improved accuracy
* Instructor dashboard for monitoring and editing attendance
* Attendance reports generation

## 🧠 Technologies Used

* Python
* OpenCV
* face_recognition
* MediaPipe
* NumPy & Pandas
* SQLite
* Streamlit (for UI)

## ⚙️ How It Works

1. The system captures video input from a camera.
2. Faces are detected and matched with stored student data.
3. If a match is found, attendance is recorded automatically.
4. If not, the user can verify identity using a student ID.
5. The system updates face data and records attendance.
6. Attendance data is stored and can be viewed or edited by instructors.

## 🎯 Goal

To provide a smart, efficient, and reliable solution for attendance management in educational environments while reducing manual effort and preventing cheating.
