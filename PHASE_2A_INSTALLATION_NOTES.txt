KNOWN INSTALLATION BLOCKER
==================================================

Issue: face_recognition_models incompatible with Python 3.14

Details:
The face_recognition_models package (v0.3.0) depends on pkg_resources,
which was removed in Python 3.14. The package uses deprecated setuptools
functionality and has not been updated since 2018.

Error message:
  "ModuleNotFoundError: No module named 'pkg_resources'"
  
When attempting to import face_recognition, it internally tries to import
face_recognition_models, which fails with the pkg_resources error.

Impact:
- face_recognition library is installed but cannot be imported
- Face recognition functionality will not be available until this is resolved
- Face detection (MediaPipe) and other CV operations remain functional

Workarounds Attempted:
- Installing setuptools (v84.0.0) - pkg_resources still not available in Python 3.14
- Reinstalling face-recognition - same issue
- Force reinstalling setuptools - no change

RESOLUTION OPTIONS
==================================================

Option 1 (Recommended for Production):
Use Python 3.11 or 3.12 where pkg_resources is still available.

Option 2 (Development Workaround):
Install a patched version of face_recognition_models that uses
importlib.resources instead of pkg_resources:
  pip install git+https://github.com/ageitgey/face_recognition_models

Option 3 (Future):
Wait for face_recognition library maintainers to update the package
for Python 3.14 compatibility.

Option 4 (Alternative):
Consider alternative face recognition libraries compatible with Python 3.14:
- deepface
- insightface
Note: This would require architecture changes.
