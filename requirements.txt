# Runtime dependencies for the Intelligent Attendance Monitoring System.
#
# Verified environment: Python 3.10.11 (Windows) with exactly the versions
# installed by this file's lower bounds. On a machine where a requirement is
# already satisfied at a newer version, pip keeps it untouched and only a
# fresh environment resolves to the newest release allowed by the range.
#
# Supported Python: 3.10 (verified on this project), 3.11 and 3.12
# (dependency constraints checked against PyPI wheel metadata, not
# machine-tested).
#
# Every package here installs from a prebuilt wheel: no C++ compiler or
# CMake is needed. Face recognition uses OpenCV's YuNet + SFace models.
# The previous dlib recogniser (face_recognition) is optional and lives in
# requirements-dlib.txt (setup.bat --with-dlib); it must be compiled from
# source and is only needed for FACE_RECOGNITION_BACKEND=dlib.
#
# Test-only tools live in requirements-dev.txt and are not needed to run
# the application.
